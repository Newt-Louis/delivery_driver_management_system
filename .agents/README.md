# Delivery Queue Manager agent workflows

This folder stores project-local, reusable workflows for the UI rebuild. It is a governed source of task instructions; `AGENTS.md` tells Codex when to read each workflow.

- `skills/` contains focused Codex skill instructions.
- `agents/` contains role prompts for a delegated or handoff task.
- `templates/` contains the per-page task record.

These files do not grant permission to change application behaviour. User instructions and `AGENTS.md` take precedence.
